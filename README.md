# STN-7 Problem Solving Assessment

## Overview

This repository contains TypeScript solutions for the STN-7 Problem Solving Assessment.

All 20 assigned problems are implemented in a single source file: `solution.ts`.

## Technologies

- TypeScript
- Node.js
- npm
- Node.js assertion module for local testing
